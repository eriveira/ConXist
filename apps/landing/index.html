The problem

Decisions get made out loud and then lost.

The backlog lags the conversation

Someone has to turn an hour of discussion into tickets and acceptance criteria. Details drop out, or the work never gets written down at all.

Coding agents start without context

Claude, Codex and other agents write code fast, but they don't know the architecture rule your CTO set last Tuesday.

Every team builds to different criteria

Design, architecture and product decisions live in people's heads and scattered docs, so each squad makes the same call differently.

Agents

Set up agents in plain language from a template: their brief, the sources they may read, the tools they may use, how carefully they think and what they give back. Every change is a draft until you publish it, every published version is kept, and any version can be put back.

Test a draft before you publish it: pick one of your meetings, run it once and see what it gives back, whether that has the shape you asked for, and each step it took. A test only reads, and nothing of it is kept. For now tests run on your own computer with your own Anthropic key. Preview

Running agents on a schedule, and the agents that do the routine work between stages, like drafting requirements from a transcript, come next. They propose, and your team decides. Coming soon

Skills

Reusable instructions that encode how your company works, so every agent and every squad applies the same development criteria. Write a skill once, import a SKILL.md your team already uses with Claude Code or Codex, or start from a built-in skill. Each skill is published as a numbered version, and an agent stays on the version it was given until someone updates it. A skill only adds instructions and cannot turn on tools by itself: adding one to an agent turns on the read-only tools it needs, and you see which.

Reference files in a skill, and keeping skills in sync with a GitHub repo, come next. Coming soon

Integrations

Works with the tools your team already uses.

Keep a workspace for each team or product: every source flows into the workspace you choose and stays separate from the others. Asking ConXist about your work from inside the app is coming soon. Reviewing what each source captures is coming soon. ConXist is a connected orchestrator. Your coding agents will reach it over API or MCP without leaving their usual setup. Coming soon
